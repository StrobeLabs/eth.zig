eth.zig benchmarks itself against its own previous releases. The suite is the ten operations that dominate a trading bot, liquidator or searcher hot loop.

| Benchmark | What it measures |
|---|---|
| `keccak256_32b` | selector, storage-slot and mapping-key hashing |
| `keccak256_1kb` | calldata- and transaction-sized hashing |
| `secp256k1_sign` | signing a transaction hash |
| `secp256k1_recover` | recovering a sender from a signature |
| `tx_hash_eip1559` | RLP-encoding an EIP-1559 transaction and hashing it |
| `abi_encode_transfer` | encoding `transfer(address,uint256)` calldata |
| `abi_decode_dynamic` | decoding `(string,bytes)` return data |
| `u256_mulDiv` | full-precision `a*b/c` with a 512-bit intermediate |
| `u256_uniswapv4_swap` | one exact-in swap-step price update |
| `dex_decode_universal_router` | decoding a real 4-command Universal Router `execute` |

## Running

```bash
zig build bench                              # all ten
zig build bench -- --filter keccak           # a subset
zig build bench -- --save results.json       # save a run
zig build bench -- --baseline results.json   # compare with a saved run
```

## Measurement

Each benchmark warms up for 200 ms, then reports the median ns/op over 31 batches of about 10 ms, with the minimum and median absolute deviation alongside. Inputs are read through an optimizer barrier on every call so nothing is constant-folded. To compare two versions, build both with `zig build bench-install --prefix DIR` and interleave them with `python3 bench/ab.py OLD NEW`, which keeps each benchmark's fastest run so interference from the rest of the machine cancels out. Full details are in [bench/README.md](https://github.com/StrobeLabs/eth.zig/blob/main/bench/README.md).
